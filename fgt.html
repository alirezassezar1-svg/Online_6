GitHub connection

        
The token is sent only to api.github.com from this device. It is never embedded in the app, never sent anywhere else, and is stored in this browser's IndexedDB only if you choose to save it.

        
        
        

          
          
        

        

        

          Required scopes, limits & costs
          
    
            
  • codespace scope — list/start/stop Codespaces.
    • 
            
  • repo + workflow scopes — dispatch GitHub Actions workflows and read run logs.
    • 
            
  • GitHub Codespaces has a monthly free quota; beyond it you are billed by GitHub. Starting a codespace consumes quota even while idle.
    • 
            
  • GitHub Actions minutes are metered for private repositories.
    • 
            
  • GitHub does not expose a public API to run arbitrary shell commands inside a Codespace. Remote command execution here is performed through GitHub Actions workflow_dispatch, which is a real execution path with real logs.
    • 
            
  • All local features keep working when you disconnect.
